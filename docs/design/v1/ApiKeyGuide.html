Get exact dates faster (optional)

A key lets yt-mirror ask YouTube for exact upload dates 50 videos at a time, so a large channel takes seconds instead of up to an hour. It is optional and only used for reading public video dates.
The key is free. Google charges nothing for this, and you do not enter any payment details. There is only a daily usage limit, and yt-mirror stays far below it.
  1. 1
    Open the Google Cloud Console
    Sign in with any Google account.
  2. 2
    Create a project
    Click the project menu at the top, then "New project". Any name works, for example "yt-mirror".
  3. 3
    Turn on the YouTube Data API v3
    Go to "APIs and services", then "Library". Search for "YouTube Data API v3" and click "Enable".
  4. 4
    Create the key
    Go to "Credentials", click "Create credentials", then "API key". Copy the key that appears.
  5. 5
    Recommended: restrict the key
    Edit the key and under "API restrictions" allow only "YouTube Data API v3".
  6. 6
    Paste it here
    Key works. Exact dates will now load quickly.
The key is stored only on this Mac. You can remove it at any time and yt-mirror keeps working without it.
