User guide / Install

Install yt-mirror

yt-mirror runs on macOS [minimum version] or later. Installing takes a few minutes and needs an internet connection.

1. Run the installer

Open Terminal (press Cmd + Space, type "Terminal", press Enter), paste this line and press Enter:
curl -fsSL https://mderis.github.io/yt-mirror/install.sh | sh
[Screenshot: Terminal after the installer finished]

2. Open the app

Click the yt-mirror icon in your Applications folder. On first start it downloads the tools it needs and shows the progress.

What the installer changes on your Mac

  • Creates one folder with the app, its tools and its data.
  • Adds a yt-mirror icon to Applications.
  • Nothing else. No admin password, no system changes.
