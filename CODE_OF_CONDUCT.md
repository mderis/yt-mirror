# Code of Conduct

This project follows the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, assume good intent, give and accept feedback about the work and not the person, and do not harass anyone.

Report unacceptable behaviour to the maintainers privately through the contact method listed in the repository's GitHub profile or security policy. Reports are handled confidentially.
